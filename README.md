# AGENET AI

**Your intelligent conversation companion.**

AGENET AI is a responsive, frontend-only chatbot demonstration built with HTML5, CSS3 and Vanilla JavaScript. It features a modern chat dashboard, simulated assistant replies, locally saved conversations and theme preferences.

## Features
- Responsive desktop and mobile chat interface
- New conversations and conversation history
- Search and delete saved conversations
- Simulated assistant responses and typing indicator
- Dark and light themes
- LocalStorage persistence
- Suggested prompt cards
- Modular JavaScript using ES modules

## Technology
HTML5 · CSS3 · Vanilla JavaScript (ES6+) · LocalStorage · Boxicons · Google Fonts

## Run locally
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Run `index.html` with the Live Server extension, or use another local static server.
4. Start a conversation.

> ES modules may not work when opening the file directly using `file://`. Use Live Server or a local HTTP server.

## Project structure
```text
AGENET-AI/

```

## Important demo limitation
This project does **not** connect to a real AI model or API. Assistant messages are generated by simple keyword-based JavaScript logic. Conversations and theme preferences are stored only in the current browser using LocalStorage.

## Future improvements
- Connect a real AI API through a secure backend
- User authentication and cloud sync
- File and image attachments
- Voice input and output
- Export and share conversations
